# Acorne

A Progressive Web App (PWA) that tracks sleep, weight, school, chores, and hobbies all in one place.

## Features

* Sleep Tracker - hours of sleep
* Weight Tracker - weight progression
* Fitness Tracker - gym, judo, calisthenics, misc (running, wall climbing, swimming)
* Chores Tracker - household routines, bills
* School Tracker - projects, assessments, tasks
* Hobbies Tracker - reading, playing guitar, drawing, coding, letter writing

## Tech Stack

* React 18
* date-fns for date handling
* lucide-react
